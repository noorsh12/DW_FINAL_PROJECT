# Movie Rental Data Warehouse Project

## Overview

This project builds a simple Data Warehouse for a movie rental business using the Sakila database.

The main idea is to take data from the original OLTP database and transform it into a Data Warehouse that can answer business questions about customers, rentals, films, stores, payments, and revenue.

---

## Project Goals

The project focuses on:

- Designing a dimensional model.
- Creating fact and dimension tables.
- Building an ETL process.
- Loading data from Sakila into the Data Warehouse.
- Writing analytical SQL queries.
- Creating a simple visualization.
